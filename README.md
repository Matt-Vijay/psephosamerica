# Psephos America

Make U.S. federal, state, and local law easy to find, understand, and verify with LLMs.

50 states. Roughly [90,000 local governments](https://www.census.gov/data/tables/2022/econ/gus/2022-governments.html), including school and special districts. Around [200,000 pages of federal regulations](https://www.congress.gov/119/bills/hconres14/BILLS-119hconres14eas.pdf) alone. The complexity is in the overlap: which rules apply depends on location, activity, exceptions, amendments, and effective dates.
